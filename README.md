## ✨ Key Features

- **🌺 Dynamic CSS Animations:** Features smooth, staggered blooming effects for flowers, petals, and glowing light particles using advanced CSS keyframes and radial gradients.
- **💖 Interactive Particle Canvas:** A dedicated HTML5 Canvas continuously renders floating heart particles that respond to user clicks with dynamic bursts.
- **🎵 Procedural Audio Synthesizer:** Utilizes the Web Audio API to generate ambient romantic chord progressions (Cmaj7, Am7, Fmaj7, G7sus4) without requiring external audio files.
- **💌 Typewriter Love Letter Modal:** An interactive modal UI that reveals a romantic message using a custom JavaScript typewriter effect.
- **📱 Responsive Layout:** Elements scale dynamically to fit the viewport using modern CSS properties like `container-type` and `cqi` units.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/v7keystudio/Interactive-Blossom.git
   ```
2. **Open the project:**
   Navigate to the project folder and open `index.html` in your favorite web browser. No build tools or dependencies are required!

<br />

## 📂 Project Structure

- `index.html` — The main structure, canvas container, and UI elements.
- `style.css` — Custom properties, keyframe animations, glowing effects, and responsive styling.
- `script.js` — Canvas particle physics, Web Audio API synthesis, and DOM interactions.
